# The Mad Bull

A small, responsive static web page inspired by the legendary bull El Toro Loco. This project is a front-end showcase built with plain HTML, CSS, and a little JavaScript for the dynamic footer year.

## Overview

The Mad Bull page presents a bold, colorful landing layout with:

- A strong hero header with a title and warm orange/yellow gradient background
- A featured image and introduction to El Toro Loco
- Informational sections describing the bull's history and reputation
- A call-to-action link to learn more
- A footer that automatically updates to the current year

This project is intentionally lightweight and serves as a simple example of a static, single-page marketing/feature page.

## Local Setup

Because this is a static site, you can run it without installing dependencies or a build tool.

### Option 1: Open directly in the browser

1. Navigate to the project folder.
2. Open `index.html` in your browser.

### Option 2: Serve locally with a simple HTTP server

From the project root, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
